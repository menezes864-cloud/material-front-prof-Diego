Sobre o Curso

O Curso Técnico em Desenvolvimento de Sistemas prepara profissionais para desenvolver aplicações Desktop, Web e Mobile utilizando as tecnologias mais utilizadas do mercado.

Durante o curso são estudadas linguagens de programação, banco de dados desenvolvimento Web, engenharia de software e desenvolvimento mobile.

Disciplinas

  • Algoritimos
  • Banco de Dados
  • HTML
  • CSS
  • JavaScript
  • Python
