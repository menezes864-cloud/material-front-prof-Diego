Sobre o Curso

O curso Técnico em Desenvolvimento de Sistemas prepara profissionais para desenvolver aplicações Desktop, Web e Mobile utilizando as tecnologias mais utilizadas pelo mercado.

Durante o curso são estudadas linguagens de programação, bancos de dados, desenvolvimento web, engenharia de software e desenvolvimento mobile.

Disciplinas

  • Banco de Dados
  • HTML
  • CSS
  • JavaScript
  • Python
