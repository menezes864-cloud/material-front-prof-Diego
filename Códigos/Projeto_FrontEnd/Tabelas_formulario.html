Resumo dos Principais Elementos

Tag Função
<table> Cria uma tabela
<tr> Cria uma linha
<th> Cabeçalho da tabela
<td> Coluna (célula de dados)
<form> Cria um formulário
<input> Campo de entrada de dados
<label> Rótulo de um campo
<select> Lista suspensa
<option> Item da lista suspensa
<textarea> Campo para textos maiores
